# Frontend Modules

Carpeta reservada para modulos nuevos del frontend.

Estructura sugerida por modulo:

```text
modules/nombre-modulo/
  nombre-modulo.component.ts
  nombre-modulo.component.html
  nombre-modulo.component.css
  nombre-modulo.service.ts
  nombre-modulo.models.ts
```

Por ahora la aplicacion principal sigue en `app.component.*`. Los modulos nuevos pueden crearse aqui y conectarse gradualmente.
